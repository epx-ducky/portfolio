# 🏗️ Grady Systemarchitektur & KI-Logik

## Systemkomponenten
1. **Frontend / Agent-Interface:** Interaktive Benutzeroberfläche zur Eingabe von Schulfächern, Noten und Lerninhalten.
2. **KI-Reasoning-Engine:** Verarbeitet Eingaben über maßgeschneiderte Prompts und Google Antigravity Agenten-Workflows.
3. **Noten- & Score-Berechnung:** Mathematisches Modell zur exakten Noten-Gewichtung nach Gymnasial-Standard (BW/KSE).

---

## KI-Agenten Workflow
```
[Schüler-Eingabe] --> [Google Antigravity Agent] --> [Analyse der Lernlücken] --> [Persönlicher Lernplan]
```
